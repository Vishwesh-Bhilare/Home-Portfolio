Resilient Offline Mesh Communication Protocol
2026
Embedded · BLE / LoRa · Mesh Networking · Protocol Design
  • Each device gets a unique ID and continuously pings nearby nodes, maintaining a live presence map of the mesh.
  • Peer discovery propagates hop-by-hop — no central coordinator, no internet required.
  • When a gateway device with internet joins, all accumulated node IDs and presence data are published upstream.
  • Designed for resilience in disconnected environments: disaster zones, remote field ops, offline campuses.
